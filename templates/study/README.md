# My xuui study

Run `npm run dev`, then open the printed local URL. Edit `xuui.studies.ts` to register designs and `studies/` for their React implementations. The studio comes from the pinned xuui dependency.

Use Play to try interactions, C to comment, and Submit review to hand feedback back to your agent. Submitted reviews stay in `.xuui/reviews/`. MCP is optional: `npx xuui mcp --project-dir /absolute/path/to/this/workspace`.

This is an experimental alpha. Keep earlier variants when they should remain reviewable, and use new IDs when advancing a direction.
