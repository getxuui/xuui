# xuui

xuui is a workspace for reviewing UI design studies and exploring their variants.

## Language

**Study**:
A collection of variants exploring the same design question or brief.
_Avoid_: Project, exploration, variant set, variant group

**Variant**:
One design alternative within a study, with its own parameters, state, and guides.
_Avoid_: Iteration, revision, variation, option

**Canvas**:
The area for viewing, panning, zooming, selecting, and measuring variants.
_Avoid_: Well, preview well

**Layer**:
A selectable rendered element within a variant.
_Avoid_: Focus state

**Group**:
A layer that contains child layers.
_Avoid_: Layer collection

**Guide**:
A horizontal or vertical alignment reference pinned to a variant and positioned from that variant’s top-left origin.
_Avoid_: Rule, ruler line

**Ruler**:
The graduated scale along the canvas edge, with zero at the active variant’s top-left corner.
_Avoid_: Rule
